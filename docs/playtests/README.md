# Playtest exports

Verbatim JSON exports of real playthroughs, archived as they are shared.

Filename convention: `NNN-YYYY-MM-DD-<short note>.json`, numbered in the order
they were reviewed, so the sequence reads as a series.

Each export is lossless — summary, every seat including private state, the
final board, and the complete event log. Reviews of these files live in
`docs/DESIGN.md`, in the changelog, alongside the rule change each one caused.
